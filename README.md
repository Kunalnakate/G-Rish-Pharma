## 🌟 Overview

**G-Rish Pharma Pvt. Ltd.** is a dynamic and dedicated Indian pharmaceutical manufacturer and global supplier. We serve healthcare providers, government tenders, and distributors worldwide, exporting high-purity finished formulations and Active Pharmaceutical Ingredients (APIs) manufactured in sophisticated, state-of-the-art **GMP and WHO-GMP approved facilities** across Maharashtra, Gujarat, and Hyderabad.

---

## 🚀 Key Features

* **Official 30 APIs Master Catalog**: Interactive molecule explorer featuring 30 core active ingredients complete with CAS Registry Numbers and Pharmacopoeial compliance standards (**USP**, **BP**, **EP**, **IP**, and **In-House**).
* **Dual-View Product Architecture**: Instant toggle between **Active Pharmaceutical Ingredients (APIs)** and **Finished Formulations & Dosage Forms** (Tablets, Capsules, Injections, Dry Syrups, Ointments, and Drops).
* **Interactive RFQ & Plant Visit Dispatcher**: Pre-filled inquiry composer routing requests directly to official procurement (`pooja.b@g-rishpharma.com`) with one-click email client integration and clipboard fallback.
* **Mobile-First Responsive Design**:
  * Stacked card transformation for the API catalog with injected accessible labels.
  * Mobile quick-action dock (Call Direct, WhatsApp, and Quick RFQ) with iOS safe-area support.
  * Animated navigation drawer with backdrop blur, touch-scrollable filter chips, and iOS auto-zoom prevention (`16px` form inputs).
* **Regulatory Compliance**: Support for CTD / eCTD dossier modules, Zone IVb stability studies, Batch Analytical CoAs, and Free Sale Certificates (FSC).
* **Standalone Architecture**: 100% pure HTML5, Vanilla CSS3, and Vanilla JavaScript—runs instantly in any browser without requiring build steps, bundlers, or package installations.

## 🛠️ Quick Start

### Option 1: Direct Browser
Simply double-click [`index.html`](index.html) or open it directly in any modern browser (Chrome, Edge, Safari, Firefox).

### Option 2: Local HTTP Server
Using Python:
```bash
python -m http.server 5173
```
Then navigate to `http://localhost:5173/`.

Using Node.js:
```bash
npx serve .
```
